# 🐍 Lógica e Programação de Computadores (1º Semestre)

Este módulo reúne os códigos e análises desenvolvidos na disciplina de **Lógica e Programação de Computadores** no curso de Análise e Desenvolvimento de Sistemas (PUC-RS).

---

## 📌 Visão Geral do Projeto

O objetivo do projeto foi o processamento, tratamento estatístico e análise exploratória de um conjunto real de dados meteorológicos históricos (`Anexo_Arquivo_Dados_Projeto_Logica_e_programacao_de_computadores.csv`):
- **Tratamento e Validação**: Leitura de arquivos estruturados, conversão de tipos de dados, tratamento de valores ausentes e detecção de anomalias térmicas.
- **Cálculos Analíticos**: Médias móveis, identificação de picos de temperatura máxima/mínima e agrupamentos por períodos.
- **Análise Exploratória (EDA)**: Implementada no Jupyter Notebook (`projeto_fase_dois.ipynb`) com gráficos e sumarização descritiva.

---

## 📁 Arquivos do Módulo

- `projeto-fase-um.py`: Script Python com o algoritmo inicial de processamento e filtragem de dados.
- `projeto_fase_dois.ipynb`: Jupyter Notebook interativo contendo a análise estatística completa e visualizações.
- `Anexo_Arquivo_Dados_Projeto_Logica_e_programacao_de_computadores.csv`: Dataset meteorológico de entrada.
- `.gitignore`: Regras de exclusão para arquivos de checkpoint e ambientes virtuais.

---

## 🚀 Como Executar

```bash
# Executar a lógica inicial
python projeto-fase-um.py

# Iniciar o notebook interativo
jupyter notebook projeto_fase_dois.ipynb
```
